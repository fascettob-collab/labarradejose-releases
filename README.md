# La barra de José — instaladores

Este repositorio solo publica los instaladores de **La barra de José** para Windows. No contiene código.

- Para instalarla por primera vez, bajá el `.exe` de la [última versión](../../releases/latest) y abrilo.
- Si ya la tenés instalada, no hace falta hacer nada: al abrirla te avisa cuando hay una versión nueva y se actualiza sola con el botón **Actualizar**. Tus expedientes y ajustes no se tocan.
